## 📖 About The Project

TravelTourF is a cross-platform mobile and desktop application built with Flutter. It delivers the full Travel & Tour Management experience across all major platforms from a single codebase. The app integrates with Firebase for authentication and real-time data, and communicates with a Spring Boot REST API for core business logic.

### Key Features

- 🌍 **Cross-Platform** — Single codebase for Android, iOS, Web, Windows, macOS, and Linux
- 🔐 **Authentication** — Login and registration with Firebase Auth
- 🗺️ **Tour Browsing** — Browse, search, and view detailed tour information
- ✈️ **Flight Search** — Search and book flights
- 📅 **Booking Management** — Create, view, and manage bookings
- 👤 **User Profile** — Personal information and booking history
- 🎨 **Beautiful UI** — Material 3 design with smooth animations
- 📡 **Real-time Updates** — Firestore integration for live data
- 🔌 **Backend Integration** — REST API communication with Spring Boot
